📊 Project Overview

This project presents a detailed data visualization and demographic analysis of India's population by age group for 2022. Instead of using only three broad age categories, the project uses 21 five-year age bands, providing a more detailed view of India's population structure. The analysis includes population distribution by age, broad age-group comparison, male–female distribution, population percentages, and an overall age-profile visualization.

🎯 Objectives

•⁠  ⁠Analyze India's population distribution across different age groups.
•⁠  ⁠Visualize population data using multiple professional charts.
•⁠  ⁠Compare population between different age categories.
•⁠  ⁠Analyze male and female population distribution.
•⁠  ⁠Calculate population percentages for broad age groups.
•⁠  ⁠Present demographic insights in a clear and professional format.

📈 Visualizations

The project includes:

1.⁠ ⁠5-Year Age Group Bar Chart — compares population across 21 age groups.
2.⁠ ⁠Broad Age Group Chart — compares "0–19", "20–64", and "65+" populations.
3.⁠ ⁠Male vs Female Stacked Chart — shows population distribution by age and sex.
4.⁠ ⁠Population Share Pie Chart — represents the percentage contribution of broad age groups.
5.⁠ ⁠Age Profile Line Graph — shows how population changes across age.

🛠️ Technologies Used

•⁠  ⁠Python
•⁠  ⁠NumPy — numerical calculations and data processing
•⁠  ⁠Matplotlib — data visualization
•⁠  ⁠PowerPoint / python-pptx — project presentation

📊 Key Findings

The expanded dataset provides a more detailed picture of India's demographic structure:

•⁠  ⁠The 20–64 years age group represents the largest portion of the population.
•⁠  ⁠The 0–19 years group represents a significant share of the population.
•⁠  ⁠The 65+ years population is comparatively smaller.
•⁠  ⁠The five-year age-band visualization makes changes in population size across generations easier to identify.
•⁠  ⁠Male and female population distributions can be compared across every age group.
